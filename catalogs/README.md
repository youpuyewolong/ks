第 1 季官方名称直接写作「口袋神探」，本地以 season=1 归档。条目包括主线故事、知识揭秘、番外、预告、主题曲等；不是 1201 集主线故事。第 3～5 季的折叠附加分组也已展开收集，数量与各专辑页显示总数一致。同一集号可能出现在附加版本中，因此上传不能仅按目录序号匹配。

每个 `kaishu/<albumId>/catalog.json` 包含来源链接、采集时间、页面总数、条目顺序与本地图片路径。图片按官方页面展示的图片地址下载，有些是缩略图；不同条目可以使用相同画面。导入媒体库时按文件内容去重，每个条目仍保留正确的封面关联。

前台分类采用本地整理的「故事 / 科学揭秘 / 番外」，可在后台逐条修改；它不是对官方所有细分类别的一比一复刻。

服务首次启动自动导入缺少的整季资料。已导入季有标记，不会每次重启覆盖后台改名、录音、排序或删除操作。手动运行 `npm run import:catalog -- catalogs/kaishu/472/catalog.json` 可补回缺失分集、更新封面和说明，同时保留已有录音、分集标题、顺序、时长和收听进度。
